## Scope and limitations

The evaluation replays public inputs with MockLLM; it is not a live-LLM or user study. The v2 set is small, labels are supplied by the lab data, and the A/A noise interval is exactly zero only because the mock run is deterministic. A stochastic production model needs a fresh held-out A/A study and human adjudication before these floors are treated as production guarantees.

- **Gate owner:** assign an engineer/team before using the gate for release.
- **Pilot scope:** test environment only; no real customer refunds are authorized by this evaluation.
- **Next eval-set version:** add adjudicated cases from new traces, preserve label provenance, then regenerate the eval set and baseline through the CLI.
